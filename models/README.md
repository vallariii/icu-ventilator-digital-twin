# Trained Models

This directory is used for trained machine-learning model artifacts generated by the project.

The trained model files are intentionally excluded from the public GitHub repository because some of the generated artifacts are large binary files.

## Models Used

The project includes models for:

### Anomaly Detection

* Isolation Forest
* LSTM Autoencoder

### Fault Classification

* Support Vector Machine
* Random Forest

### Remaining Useful Life Estimation

* XGBoost models using C-MAPSS data
* XGBoost model using FEMTO data

## Training

The model training scripts are available in the `src/` directory.

Examples include:

```bash
python src/train_iforest.py
python src/train_lstm_autoencoder.py
python src/train_fault_classifier.py
python src/train_xgb_rul.py
python src/train_xgb_femto_rul.py
```

The generated model files can be stored locally when running the project.
